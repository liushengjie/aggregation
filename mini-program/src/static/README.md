# 静态资源目录

## 目录说明

- `images/` - 图片资源
  - `logo.png` - 应用Logo
  - `share.png` - 分享图片
  
- `icons/` - 图标资源
  - `refresh.png` - 刷新图标
  - `back.png` - 返回图标
  
- `tabbar/` - TabBar图标
  - `home.png` - 首页图标（未选中）
  - `home-active.png` - 首页图标（选中）

## 注意事项

1. 图片建议使用 PNG 格式
2. TabBar 图标建议尺寸：81x81px
3. 其他图标建议尺寸：40x40px
4. 图片大小建议控制在 100KB 以内
