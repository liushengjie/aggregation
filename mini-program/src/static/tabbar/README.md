# TabBar 图标说明

小程序需要以下图标文件，请准备以下尺寸的图标：

## 需要的图标文件

1. **focus.png** / **focus-active.png** - 聚焦页面图标（81x81px）
2. **drama.png** / **drama-active.png** - 热剧页面图标（81x81px）
3. **trends.png** / **trends-active.png** - 热榜页面图标（81x81px）

## 图标要求

- 尺寸：81x81px（微信小程序推荐尺寸）
- 格式：PNG（支持透明背景）
- 颜色：
  - 未选中：灰色 (#666666)
  - 选中：主题色 (#667eea)

## 临时方案

如果暂时没有图标，可以：
1. 使用纯色方块作为占位
2. 或者暂时移除 tabBar 配置（在 pages.json 中注释掉 tabBar 部分）

## 生成图标

可以使用在线工具或设计软件生成：
- Figma
- Sketch
- 在线图标生成器
