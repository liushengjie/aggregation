# 系统截图目录

本目录用于存放项目文档中的系统截图。

## 截图要求

### 推荐的截图尺寸
- **主要截图**: 1920x1080 (16:9)
- **细节截图**: 1280x720 或更高分辨率

### 截图文件命名规范

请使用以下命名规范：

- `dashboard-main.png` - 主界面聚合面板
- `insights-view.png` - 趋势洞察视图
- `settings-view.png` - 系统设置界面
- `account-management.png` - 平台账号管理
- `login-page.png` - 登录页面
- `content-card-detail.png` - 内容卡片详情

### 如何添加截图到 README

1. 将截图文件保存到本目录
2. 在 `README.md` 中找到对应的位置
3. 使用以下格式替换注释：

```markdown
![主界面 - 聚合面板](docs/screenshots/dashboard-main.png)
```

或者使用绝对路径（GitHub）：
```markdown
![主界面 - 聚合面板](https://raw.githubusercontent.com/your-username/your-repo/main/docs/screenshots/dashboard-main.png)
```

## 截图清单

请确保添加以下截图：

- [ ] 主界面 - 聚合面板 (`dashboard-main.png`)
- [ ] 趋势洞察视图 (`insights-view.png`)
- [ ] 系统设置界面 (`settings-view.png`)
- [ ] 平台账号管理 (`account-management.png`)
- [ ] 登录页面 (`login-page.png`) - 可选
- [ ] 内容详情 (`content-card-detail.png`) - 可选

## 截图工具推荐

- **Windows**: Snipping Tool, Snip & Sketch, ShareX
- **macOS**: Screenshot (⌘ + Shift + 4)
- **Linux**: Flameshot, Spectacle

## 注意事项

1. 截图时请隐藏敏感信息（如真实账号、密码等）
2. 使用示例数据或打码处理敏感信息
3. 保持截图风格一致
4. 确保截图清晰可读
